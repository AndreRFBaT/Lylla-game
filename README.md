Project structure:

```bash
├── 00_Globals
│   ├── GlobalLevelManager.gd        # Singleton script managing level switching, persistence, and scene loading
│   ├── GlobalLevelManager.gd.uid    # Godot 4 Unique Identifier file for resource tracking
│   ├── global_player_manager.gd     # Singleton script tracking global player states (health, stats, inventory)
│   └── global_player_manager.gd.uid # Godot 4 UID file for the player manager script
├── Enemies
│   ├── Enemy                        # Base node/scene definitions and variations for enemy entities
│   └── Scripts                      # AI behavioral scripts, movement logic, and state machines for enemies
├── export_presets.cfg               # Godot build/export configuration file for targeting platforms (PC, Web, etc.)
├── GeneralNodes
│   ├── HitBox                       # Reusable Area2D component for inflicting damage on collision
│   └── HurtBox                      # Reusable Area2D component for detecting incoming damage from HitBoxes
├── GUI
│   ├── player_hud                   # Heads-Up Display scenes/scripts (health bars, inventory, UI counters)
│   └── scene_transition_gui         # UI overlays and animations for smooth screen fades/level transitions
├── icon.svg                         # Default Godot project icon used for application builds
├── icon.svg.import                  # Import settings generated by Godot for the project icon
├── Levels
│   ├── Area01                       # Specific level layout/map instances and local scene nodes
│   ├── level_transition.tscn        # Trigger area scene for teleporting the player to new levels
│   ├── player_spawn.tscn            # Marker2D scene dictating where the player instantiates in a new area
│   └── Scripts                      # Level-specific event scripts and trigger mechanics
├── Player
│   ├── Audio                        # Sound effects (footsteps, attack sounds) dedicated to the player
│   ├── Scene                        # The main Player CharacterBody2D scene hierarchy
│   ├── Scripts                      # Character controller logic, input handling, and state machine scripts
│   └── Sprites                      # Animation frame sheets and texture assets for the player
├── playground.tscn                  # Sandbox/testing level used for debugging mechanics without affecting main levels
├── project.godot                    # Core project settings, autoload definitions, input mappings, and display configs
├── Props
│   ├── Plants                       # Interactive or destructible environmental props (e.g., bushes, flowers)
│   └── Sprites                      # Visual assets and textures for world props
└── Tile Maps
    ├── grass 01.tscn                # Pre-configured tilemap layer scene for ground/terrain rendering
    ├── house.tscn                   # Structure tilemap scene including static collision layers
    ├── Scripts                      # Custom scripts for handling dynamic tile behaviors or generation
    └── Sprites                      # Source tilesets and sprite sheets used by TileMapLayers
```
